description: 現在ブランチの差分を、コンテキストを持たないサブエージェントでコードレビューする。ユーザーが「レビューして」と依頼したときや、PR 前に使う。
when_to_use: コードをレビューする / レビューして / PR 前にレビュー確認するとき
---

コードレビューは**本体（あなた）が自分で行わず**、実装の会話文脈を継承しない
**新規サブエージェント**に任せる。手順は次のとおり。

1. Agent ツールで `subagent_type: "code-reviewer"` を **1 回**起動する。
   - **`fork` は使わない**（fork は文脈を継承してしまう）。`code-reviewer` は新規＝コンテキスト無しで走る。
   - プロンプトには「ベースブランチは `main`。現在ブランチの差分（コミット済み＋未コミットの作業ツリー変更）を
     レビューし、`.claude/agents/code-reviewer.md` の指針と出力形式に従うこと」と伝える。
   - フォールバック: `code-reviewer` が subagent_type として使えない環境なら、`general-purpose` を新規起動し、
     プロンプト冒頭で「まず `.claude/agents/code-reviewer.md` を Read し、その指針に完全に従え」と指示する。

2. サブエージェントの最終メッセージ（指摘一覧と末尾の `REVIEW_RESULT:` 行）を、
   **握り潰さずユーザーへ要約提示**する。重大度の高い指摘は省略しない。

3. 末尾の判定を明示する:
   - `REVIEW_RESULT: BLOCK` … 重大（Critical/Major）指摘あり。修正方針を添えて伝える。
   - `REVIEW_RESULT: PASS` … 重大な指摘なし。

このスキルはレビュー結果を報告するだけで、コードの修正や PR 作成は行わない
（修正するかどうかはユーザーの指示に従う）。
