# 0002: 認証保護は `/admin` のみ

**状態**: 採用

## 文脈
本サイトはブログ（公開コンテンツが大半）で、認証が必要なのは投稿・編集を行う管理機能のみ。

## 決定
[`auth.config.ts`](../../auth.config.ts) の `authorized` コールバックで **`/admin/*` 配下のみ**を保護し、
未ログインは `/login` へリダイレクト。それ以外のルートは全て公開とする。
ミドルウェア適用範囲は [`proxy.ts`](../../proxy.ts) の `matcher`（API・静的アセットを除外）。

## 結果
- 公開ページはミドルウェアで弾かれず軽量。保護対象が明確。
- 将来 admin 以外に保護領域が必要になったら `authorized` を拡張する。詳細は [auth.md](../auth.md)。
